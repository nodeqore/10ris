# Changelog

All notable changes to the 10RIS specification are recorded in this file. Published versions are retained at their original paths.

## v1.0 — 2026-09-22

Initial published release of the 10-Inch Rack Interface Specification (10RIS).

- Defines the front-panel width, rail mounting-hole centre-to-centre spacing, clear opening, vertical 1U spacing, and two core mounting-hole types.
- Includes four normative SVG reference figures.
- Establishes self-declaration requirements and non-normative implementation guidance.
